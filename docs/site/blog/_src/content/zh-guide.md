# 使用说明：和 Tacit 一起工作

DSH-projects 里你主要打交道的是两样东西：个人助理 Tacit，和一块叫「待你决定」的看板。下面按第一次用的顺序走一遍。

## 1. 装上

需要 DeepSeek Harness 0.2.x 和 Node 24 以上。没装过 DeepSeek Harness 的话，先 `npm install -g @deepseek-ai/dsh`。

```
git clone https://github.com/hovocope135-tech/DSH-projects
cd DSH-projects/plugin
dsh plugin --profile web add "$(pwd)"
dsh --profile web
```

打开它给出的地址，左侧会多出「个人助理」和「项目」。模型跟着你在 DeepSeek Harness 里的配置走。

可选：装了 Claude Code 或 Codex 的命令行，任务就能换给它们执行；装了飞书命令行（lark-cli）并授权，Tacit 能只读你的飞书消息。

## 2. 认识 Tacit

第一次打开会直接进「个人助理」的对话，右边是「待你决定」。这个助理默认叫 Tacit。接着会弹出一个两步的小窗口：选它的性格（最多三个），起个名字，定一个呼出快捷键（默认 ⌥M）。不想弄就点跳过，以后在「助理设置 → 性格与快捷键」里能改。

先对它说一句：「记住：我看东西习惯先看结论，再看细节。」它会记进「关于你」，带着你的原话，之后每个对话都知道。

![左边对 Tacit 说「记住」，右边记忆页的这一条附着原话](img/u6-memory.jpg "对 Tacit 说「记住」，这一条就进了「关于你」，下面附着原话。")

## 3. 你可以让 Tacit 做什么

Tacit 不进项目干活，它看着所有项目。在个人对话里，你明确让它做的事，它可以替你做：

| 你说 | 它做什么 |
| --- | --- |
| 「帮我建个项目：招聘前端工程师」 | 新建一个项目 |
| 「把这件事交给招聘那个项目：……」 | 把你的原话原样交给项目，开成任务；它自己的补充另外标明 |
| 「还有什么在等我？」「今天做了什么？」 | 读看板和时间线回答，每条带出处 |
| 「市场部群里刚才说了什么？」 | 读收集到的飞书消息 |
| 「跟二面题目那个任务说，再加一道 CSS 的题」 | 给这个任务带话 |
| 「第二个方案就行」 | 替你回答一个等你拍板的问题 |
| 「验收吧」 | 先告诉你改了什么，等你回「确认」再验收 |
| 「记住：……」 | 记进「关于你」，带着原话 |
| 「看看我电脑上那份合同」 | 读你允许的电脑文件夹，只读 |
| 「这个项目以后用便宜点的模型」 | 记成项目的模型策略，再按策略换模型 |
| 「把那个测试项目删了」 | 移进回收站，随时能恢复 |

它不以你的名义发消息。没有你的一句话，它不拍板，也不验收。

## 4. 交代第一件事

1. 左侧「项目」旁边点 +，起个名字。可以填一个文件夹，执行者会在里面干活；不填会新建一个同名工作区。也可以直接对 Tacit 说「帮我建个项目」。
2. 在项目对话里说一句话，讲清三件事：要做什么，上下文在哪，标准是什么。比如：「根据『岗位描述.md』写一份二面题目 interview.md：3 道动效和交互细节相关的题，每题附评分要点。」同一句话也可以对 Tacit 说，它会把原话原样交给这个项目。
3. 项目助理会先开工能开的，再问你没说清的。直接回答就行。

![项目对话：一句话开出一个任务，交付后告诉你等你验收](img/guide-project.jpg "项目对话。一句话开出任务，交付后告诉你等你验收。")

## 5. 看任务做到哪了

右边「项目任务」里能看到开出的任务。点进去，右边是任务详情：背景和你的原话，怎么算完成，产出，读过的文件，进展。这就是这件事的上下文包。

![任务详情：背景、原话、怎么算完成 4/4、产出、读过的文件、进展](img/guide-task.jpg "任务详情。「怎么算完成」由执行者自己勾。")

想换执行者：任务详情 →「执行」→「执行方式」，在 DeepSeek Harness、Claude Code、Codex 之间换，模型也能单独换。想自己动手，点「我来接手」，做完点「交还」。注意：Claude Code 和 Codex 当执行者时不弹权限确认，也没有沙箱，你这个系统用户能读写的它都能读写。

## 6. 验收和拍板

任务做完会出现在「待你决定」的「等你」一栏。

- 点卡片打开任务。「交付」里网页直接渲染，图片直接显示，文档直接预览。
- 满意：点「验收通过」，或者对 Tacit 说一句「验收吧」。
- 要改：点文件上的「请求修改」，输入框里会先填好这个文件名，接着写要改什么。
- 执行者中途要你拍板时，会给一张选项卡片，推荐项标出来；都不合适就直接打字回答。

## 7. 待你决定

一块看板，三栏：等你，进行中，今天完成。任务、飞书里等你回的消息、Tacit 的提醒都是卡片。点任务卡打开任务；点消息卡，一句回复会写进输入框，你改完再发。

![待你决定：等你一栏的任务和飞书提醒，进行中一栏的任务](img/guide-board.jpg "待你决定。卡片上没有按钮：点一下打开任务，或者把回复写进输入框。")

## 8. 让上下文自己进来

这几项都是只读，随时能关：

- **飞书**：「助理设置 → 飞书实时读取」。授权后 Tacit 能读消息和文档，不能发。有人在等你回，会出现在「等你」里；要不要主动提醒，在「飞书主动提醒」里选。
- **电脑文件**：「助理设置 → 电脑文件」，选「指定文件夹」或「全部文件」，也可以暂停。
- **屏幕**：在装了 Screenpipe 的电脑上运行 DSH-projects 的设备程序，它每分钟读一次窗口里的文字，只传文字，截图留在电脑上。每 10 分钟整理成一条时间线，认得出项目的归到项目。

![时间线：每段活动带着用到的应用和所属项目](img/timeline-apps.jpg "时间线。")

## 9. 记忆、模型和夜里那一轮

- **记忆**：「助理设置 → 高级 → 记忆」。「关于你」每条带原话，能改，能忘掉；「工作」每条带依据。
- **助理与模型**：「助理设置 → 高级 → 助理与模型」。每个助理一页：什么时候醒，每轮读到什么，用什么模型。可以用一句话给项目写模型策略。
- **夜里想一轮**：夜里电脑闲着时，Tacit 把这一天过一遍，早上最多留三件事在「等你」里：一件可以做的，一件可以看的，一句想说的，每件写明出处，另有一页日记。
- **做事说明**：同一个问题你在交付后说了三次，夜里它会起草一版新的做事说明，早上由你选：用新版，先试一次，或者保持旧版。

## 10. 出问题时

| 现象 | 怎么办 |
| --- | --- |
| 页面显示「连不上服务，正在重连…」 | 服务停了或在重启。等它回来，页面会自己连上，不用重新登录。 |
| 任务停在「失败」 | 打开任务看最后一条进展。多半是模型或网络错误，对它说「接着做」。 |
| 换成 Codex 后没动静 | Codex 需要在这台机器上自己登录过，没登录会报错并停住。 |

数据都在运行它的那台机器上。飞书和电脑文件都是只读，只读你允许的部分。删一个项目是移进回收站，随时能恢复。
